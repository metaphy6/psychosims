# content/

> Content pipeline for Psychosims: patient manifests, nine-axis synthesis,
> study fields, and the fictional encyclopedia.

All authored content lives here. It passes through the content-integrity gate
(no real DSM/ICD labels, no real drug brands) before it can be loaded by the app
or signed for distribution.

## Layout

- `manifests/` — canonical patient manifests.
- `taxonomy/` — fictional naming registry and naming rules.
- `encyclopedia/` — in-game fictional reference entries.
- `tests/` — pipeline validation tests.

See [`docs/specs/AGE-RATING-AND-CONTENT-STRATEGY.md`](../docs/specs/AGE-RATING-AND-CONTENT-STRATEGY.md)
and [`docs/code/ARCHITECTURE.md`](../docs/code/ARCHITECTURE.md) §5.
