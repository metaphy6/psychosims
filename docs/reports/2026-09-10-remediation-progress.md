Production session bindings and model measurement tools now honor the shared
retry limit (0–2 corrections, default 2). Zero makes one initial generation
attempt; rejected output still resolves to the deterministic fallback. Production
binding tests cover each limit and exactly one persisted action. The outcome
catalog was regenerated for the changed source provenance; its three proofs are
unchanged. This is the final implementation slice, `remediation-20260910-final`.

The contract gate deliberately excludes model-acceptance tests. The complete
[three-model baseline](2026-09-10-model-baseline.md) retains its latency and raw
dialogue-quality failures. Subsequent prompt 1.1 diagnostics and 24 independently
reviewed prompt/sanitizer regressions improve specific failures, but a complete
new three-model matrix and physical-device acceptance have not passed. An
accidental unrestricted app-test invocation was stopped; it is recorded as
aborted and is not acceptance evidence.
